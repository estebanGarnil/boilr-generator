# Fichiers à importer

Placer ici les CSV destinés à LOAD CSV. Ce dossier est monté en lecture seule
sur /var/lib/neo4j/import. Exemple : file:///articles.csv.

Aucun import n'est déclenché automatiquement. Les imports massifs avec
neo4j-admin nécessitent une procédure distincte et une base arrêtée.
